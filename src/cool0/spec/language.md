# cool0 언어

**이 명세는 동결이다.** cool0 는 부트스트랩 전용 언어이며 기능을 더하지 않는다.
부족한 것은 cool1 이 채운다.

이 문서는 **cool0 프로그램이 무슨 뜻인가**를 정한다. 생김새는
[`grammar.ebnf`](grammar.ebnf) 가, 공식 구현이 그 뜻을 wasm 으로 어떻게 옮기는지는
[`implementation.md`](implementation.md) 가 맡는다.

기준은 하나다 — **wasm 을 모르는 사람에게도 설명할 수 있는 규칙이면 여기 있다.**

---

## 1. 원칙

cool0 는 **컴파일러를 실수 없이 손으로 구현할 수 있는 최소 언어**다. 그 외의
목표는 없다.

- **안전 규칙은 별칭(aliasing)과 가변성만.** 소유권·수명·자동 해제(RAII)가 없다.
  cool0 컴파일러는 순수 함수라 한 번 돌고 호스트가 메모리를 회수하므로 **아무것도
  해제하지 않는다.** 그래서 소유권 추적이 필요 없다.
- **기본 불변.** `mut` 으로만 연다. 규칙 하나가 `let`/`&`/`[]` 전부에 적용된다.
- **숨은 흐름 없음.** 암묵 변환 없음, 연산자 오버로딩 없음, 소멸자 없음, 예외 없음.
- **같은 일을 하는 기능을 둘 두지 않는다.** 루프는 `for` 하나다.

## 2. 어휘

소스는 **ASCII 전용**이다 (`0x09 0x0A 0x0D`, `0x20`–`0x7E`). 그 밖의 바이트는 오류.

토큰의 생김새는 [`grammar.ebnf`](grammar.ebnf) 의 어휘 절에 있다. 여기서는 뜻만
정한다.

- 주석 `// 줄 끝까지`
- 정수 리터럴 `123`, `0xFF`, `0b1010`. `_` 를 자리 구분에 쓸 수 있다. 값은 32비트에
  들어가야 한다 (`0`–`0xFFFFFFFF`). **타입은 쓰이는 자리에서 받는다** — `i32` 나 `u32`
  중 문맥이 요구하는 쪽이고, 요구가 없으면 `i32` 다. 이것이 유일한 추론이다 (§9)
- 문자 리터럴 `'a'`. 탈출은 `\n \t \r \0 \\ \'` 뿐. 값은 `u32`
- 문자열 리터럴 `"..."`. 탈출은 위와 같고 `\"` 추가. 타입은 `[]u8`
- `true` `false`

**키워드** — 전부 19개:

```
fn struct enum const let mut if else for break continue
return match unsafe as true false slice slice_mut
```

`_` 는 어휘적으로는 그냥 식별자다. **match 의 와일드카드 자리에서만** 특별하다.

## 3. 타입

| | |
|---|---|
| `i32` | 부호 있는 32비트 |
| `u32` | 부호 없는 32비트 |
| `bool` | `true`/`false`. 정수가 아니다 — 조건 자리에 정수를 쓸 수 없다 |
| `u8` | **저장 전용.** 슬라이스 원소와 struct 필드로만. 읽으면 `u32`, 쓸 때 잘린다. `u8` 지역변수도 `u8` 산술도 없다 |
| `[]T` `[]mut T` | 슬라이스. 포인터와 길이의 쌍이다 |
| `&T` `&mut T` | 대여. §7 |
| `*T` | 생 포인터. 역참조는 `unsafe` 안에서만. §8 |
| struct | §4 |
| enum | §4 |

메모리에 놓일 때의 크기와 정렬은 [`implementation.md`](implementation.md) §2 에 있다.

슬라이스에는 읽기 전용 필드 둘이 있다. **`s.len`** 은 `u32`, **`s.ptr`** 은 `*T` 다.
`s.ptr` 은 슬라이스가 가변이어도 같은 `*T` 이며, 부분 슬라이스는 §5의 내장 식과
조합해 만든다.

**암묵 변환은 없다.** `as` 로만 바꾼다. `as` 는 `i32`↔`u32`↔`*T` 사이의 비트 재해석이며
값을 바꾸지 않는다. `bool` 은 `as` 의 대상이 아니다. 다만 `&mut T` 를 `&T` 자리에,
`[]mut T` 를 `[]T` 자리에 쓰는 것은 변환이 아니라 **가변성 약화**다. 값이나 표현은
그대로이고, 쓰기 권한만 버린다.

### 값으로 옮길 수 없는 것

집합체(struct·enum)는 **값으로 전달하거나 반환할 수 없다.** `&T`/`&mut T` 로 넘기거나
슬라이스에 담는다. 지역변수로 두는 것과 리터럴로 만드는 것은 된다.

**슬라이스는 반환할 수 없다.** 인자로 넘기는 것은 된다. 대여도 반환할 수 없다 (§7).

**지역변수는 `u8` 도 대여 타입도 될 수 없다.** `u8` 은 저장 전용이고, 대여는 인자
자리에서만 산다.

## 4. 선언

```cool
fn name(p: T, q: T) -> T { ... }     // -> 를 생략하면 반환값 없음
struct Name { a: T, b: T }
enum Name { A, B(T), C(T, T) }
const NAME: T = <상수식>;
```

**최상위 선언은 순서에 상관없다.** 컴파일러는 2패스다 — 먼저 모든 선언을 모으고
그다음 본문을 컴파일한다. 상호 재귀가 그냥 된다.

**struct 필드와 enum 페이로드는 집합체도 대여도 될 수 없다.** 스칼라·슬라이스·생
포인터만 담긴다. 그래서 복사 코드 생성이 완전히 사라지고 — 모든 저장이 스칼라 하나다
— 재귀적 타입이 문법으로 불가능해져 크기 계산에 순환 검사가 필요 없다. 집합체를
품으려면 `*T` 로 가리키거나 `[]T` 에 담는다.

`const` 의 타입은 `i32` `u32` `bool` 뿐이다. 상수식은 리터럴·다른 상수·`as`·단항·이항
연산이며 컴파일 때 접힌다. 상수끼리는 순서에 상관없이 참조할 수 있고, 자기를 도로
참조하면 오류다. 상수식의 0 나눗셈은 트랩이 아니라 컴파일 오류다.

배치(오프셋·크기·정렬·태그)는 [`implementation.md`](implementation.md) §2 가 정한다.

## 5. 식

우선순위, 높은 것부터:

| | |
|---|---|
| `f(..)` `a[i]` `s.f` `p.^` | 호출·인덱스·필드·역참조 |
| `-x` `!x` `&x` `&mut x` | 단항 |
| `as` | |
| `* / %` | |
| `+ -` | |
| `<< >>` | `u32` 는 논리, `i32` 는 산술 |
| `& ^ \|` | 이 순서로 |
| `== != < > <= >=` | **연쇄 금지.** `a < b < c` 는 오류 |
| `&&` | 단축 평가 |
| `\|\|` | 단축 평가 |

`a[i]` 는 **경계 검사**한다 (§10). `i` 의 타입은 `u32` 다 — 음수 첨자가 문법으로
불가능해진다.

`p: *T`에 `u32`를 더하면 그 수만큼의 **원소**를 건너뛴 `*T`가 된다. 즉 주소에는
`i * sizeof(T)`가 더해진다. 생 포인터이므로 결과 주소의 유효성은 검사하지 않는다.

**시프트의 오른쪽도 `u32`** 다. 개수는 부호가 없다. 나머지 이항 연산자는 양쪽 타입이
같아야 한다.

`p.^` 는 `&T` `&mut T` `*T` 전부에 쓴다. `*T` 일 때만 `unsafe` 가 필요하다 (§8).

### 집합체 리터럴

구조체 리터럴 `Name{ a: 1, b: 2 }`, enum 리터럴 `Name.Variant` / `Name.Variant(x)`.
필드는 **전부, 선언 순서대로** 적는다.

집합체 리터럴은 `let` 초기화식과 대입 우변의 **최상위에서만** 쓸 수 있다. 거기서
대상 장소에 직접 써진다 — 임시도 복사도 없다. 다른 자리에 적으면 오류다.

문법에서는 `if`/`for`/`match` 헤더의 최상위에 온 `Name{` 를 블록의 시작으로 읽는다.
괄호·대괄호·인자 목록 안에서는 그 제한이 풀린다 — 블록이 뒤따를 수 없어 모호하지
않기 때문이다.

### 생 포인터에서 슬라이스 만들기

`slice(p, len)` 과 `slice_mut(p, len)` 은 함수 호출이 아니라 내장 **식**이다. `p`는
`*T`, `len`은 `u32`여야 하며, 각각 `[]T`와 `[]mut T`를 만든다. 둘 다 `unsafe`
안에서만 쓸 수 있다. 두 피연산자가 이미 슬라이스의 `(ptr, len)` 표현이므로 이 식
자체는 값을 바꾸지 않는다.

## 6. 문

```cool
let x: T = e;           // 불변
let mut x: T = e;       // 가변
let x = e;              // 타입 표기는 생략할 수 있다. 초기화식의 타입이 된다
x = e;                  // 대입. 가변 장소에만 (§9)
x += e;                 // += -= *= /= %= &= |= ^= <<= >>=
f(x);                   // 호출은 문이 된다. 문이 되는 식은 호출뿐이다

if e { } else if e { } else { }

for { }                       // 무한
for e { }                     // 조건
for let mut i = 0; e; s { }   // 초기화·조건·후처리

break;  continue;  return;  return e;

match e {
    A       => { }
    B(x)    => { }
    C(x, y) => { }
    _       => { }
}

unsafe { }
```

- `for` 하나뿐이다. `while` 도 `goto` 도 없다. `break`/`continue` 는 가장 안쪽 루프에만
  적용된다 (레이블 없음)
- `if`/`for` 의 조건은 `bool` 만
- **`match` 는 문이다.** 값을 만들지 않는다. 팔은 블록이다
- **패턴은 한 겹이다.** `C(Int(x), y)` 같은 중첩은 오류. 바인딩은 식별자만
- `match` 의 대상은 enum **장소**여야 한다 (`match n.^ { }` 처럼). 바인딩은 페이로드의
  복사본이고 불변이다
- `unsafe` 는 §8

## 7. 대여 — 규칙 하나

`&T` 는 읽기 전용, `&mut T` 는 독점이다. 그리고:

> **`&x` / `&mut x` 는 호출의 인자 자리에서만 쓸 수 있다.**

지역변수에 묶을 수 없고(`let r = &mut x;` 는 오류), 반환할 수 없고, struct 에 담을
수 없다. 따라서 **대여는 그 호출이 끝나면 반드시 죽는다.**

그래서 별칭 검사가 이것뿐이다:

> **한 호출의 인자 목록 안에서 어떤 지역변수를 `&mut` 로 빌렸는데, 그 지역변수가
> 그 목록 안에 또 나오면 오류.**

"또 나온다"는 형태를 가리지 않는다 — 빌리든, 값으로 읽든, 다른 식 속에 있든 같다.
빌림의 뿌리 지역변수는 `.f`/`[i]`/`.^` 를 타고 내려간 밑바닥이다.

```cool
f(&mut x, &mut x)    // 오류
f(&x, &mut x)        // 오류
f(&mut x, x)         // 오류
f(&mut a[i], a[j])   // 오류 -- 뿌리가 둘 다 a
f(&x, &x)            // 된다
g(p, p)              // 된다 -- p 가 &mut T 매개변수여도. 새 대여가 아니다
```

매개변수가 대여 타입인 것은 되고, 그것을 다른 함수에 그대로 넘기는 것도 된다 —
새 대여를 만드는 것이 아니기 때문이다.

수명 분석도, 흐름 병합도, 스코프 추적도 없다. 이것이 cool0 가 안전 규칙에서 가져오는
전부다.

## 8. unsafe

```cool
unsafe { }
```

**`unsafe` 가 허용하는 것은 `*T` 의 역참조와 `slice`/`slice_mut`뿐이다.** 그 밖에
어떤 규칙도 풀리지 않는다. 집합체를 값으로 넘기는 것도, 대여 규칙도, 타입 검사도
`unsafe` 안에서 똑같이 적용된다.

`*T` 는 `as` 로 `u32` 와 오갈 수 있으므로, 생 포인터는 사실상 "검사 없는 주소"다.
`p.^` 로 읽고 쓸 때 경계 검사가 없고, 정렬도 확인하지 않는다.

`slice`/`slice_mut`이 만든 슬라이스도 인덱싱할 때 `i < len`만 검사한다. `p`부터
`len`개 원소가 실제 메모리에 존재하는지, 올바르게 정렬됐는지, 다른 참조와 충돌하지
않는지는 검사하지 않는다. 거짓 범위를 만드는 순간부터 그 책임은 `unsafe` 작성자에게
있다.

## 9. 정적 의미론

컴파일 때 확인하는 것들. **검사는 함수 하나만 보고 끝난다** — 흐름 분석도 수명
분석도 없다.

### 가변인 장소

| 장소 | 가변인 조건 |
|---|---|
| 지역변수 | `mut` 으로 선언된 것 |
| `s.f` | `s` 가 가변인 것 |
| `a[i]` | `a` 가 `[]mut T` 인 것 |
| `p.^` | `p` 가 `&mut T` 나 `*T` 인 것 |

**매개변수는 `mut` 이 붙을 자리가 없으므로 언제나 불변이다** — 고치려면 지역변수로
받는다. `[]mut T` 매개변수를 통해 원소를 고치는 것은 되고, 그 매개변수 자체를
`&mut` 로 빌리는 것은 안 된다.

### match 의 완전성

`match` 는 **완전해야 한다** — 모든 배리언트를 다루거나 `_` 가 있어야 한다. `_` 는
마지막 팔이어야 하고, 같은 배리언트를 두 번 다루면 오류다. 바인딩 개수는 배리언트의
페이로드 개수와 같아야 한다.

### 반환

반환 타입이 있는 함수는 **모든 경로에서 반환해야 한다.** 흐름을 끊는 것은 넷이다:

- `return`
- 양쪽이 다 끊는 `if`/`else`
- `break` 없는 무한 `for`
- 모든 팔이 끊는 완전한 `match`

### 이름

최상위 이름은 겹칠 수 없고, 내장 타입 이름(`i32` `u32` `bool` `u8`)을 쓸 수 없다.
지역변수는 같은 스코프에서 겹칠 수 없고, 최상위 이름을 가릴 수 없다. 안쪽 블록에서
바깥 지역변수를 가리는 것은 된다.

### 중첩 한계는 64 다

컴파일러가 재귀 하강이고 섀도 스택이 고정 크기라 한계가 있어야 한다. 세는 것이
둘이고 둘 다 64 다.

| | |
|---|---|
| 식 트리의 깊이 | 잎이 1. 합성 노드는 `1 + max(자식)`. `1+1+1+...` 은 파서에는 반복이지만 트리로는 깊다 |
| 문법 중첩의 깊이 | 식 하나를 읽을 때마다 하나. 괄호·단항 연산자·인자·첨자가 각각 한 겹이다. 타입과 블록과 `else if` 사슬도 함께 센다 |

세는 법도 정해 둔다. 계수기는 0 에서 시작하고, 들어갈 때 **64 이상이면 오류**,
아니면 하나 올리고 나올 때 내린다. 그래서 실제로 허용되는 것은 64 겹이다.

`expression nests too deeply`, `type nests too deeply`, `block nests too deeply`.

## 10. 런타임 의미론

돌 때 일어나는 일. **정의되지 않은 동작이 없다** — 잘못된 것은 전부 트랩이다.

| | |
|---|---|
| 정수 산술 | **랩어라운드**한다 (2의 보수). 오버플로 검사는 없다 |
| 시프트 양 | 32 로 나눈 나머지만 쓴다 |
| `/` `%` 의 0 나눗셈 | **트랩** |
| 부호 있는 나눗셈 오버플로 | **트랩** (`i32::MIN / -1`) |
| `a[i]` 의 범위 밖 | **트랩** |
| `&&` `\|\|` | 단축 평가. 왼쪽으로 결정되면 오른쪽을 평가하지 않는다 |
| `u8` 읽기 | 제로 확장으로 `u32` |
| `u8` 쓰기 | 아래 8비트만 남기고 잘린다 |
| 평가 순서 | 왼쪽에서 오른쪽 |

집합체 리터럴은 대상 장소에 **직접** 써진다. 임시 사본이 생기지 않으므로 부분적으로
써진 상태가 관찰될 수 있다 — 다만 그것을 관찰할 방법이 언어 안에 없다.

`unsafe` 안의 `*T` 역참조는 검사가 없다. 범위 밖 주소는 wasm 이 트랩하지만, 유효한
주소를 엉뚱하게 읽는 것은 막지 않는다.

## 11. 의도적으로 없는 것

| | |
|---|---|
| 소유권, 수명, 자동 해제 | 컴파일러가 순수 함수라 아무것도 해제하지 않는다 |
| 오버플로 검사 | 랩어라운드로 정의했다. wasm 이 공짜로 하는 일이다 |
| 제네릭, 인터페이스, 클로저 | 컴파일러를 쓰는 데 필요 없다 |
| 모듈·임포트 | 한 파일이 한 프로그램이다 |
| `i64`/`u64`, 부동소수점 | 주소가 32비트고 컴파일러는 실수를 쓰지 않는다 |
| 문자열 타입 | `[]u8` 이면 된다 |
| `while`, `goto`, 레이블 | `for` 하나. wasm 이 구조적이라 goto 는 내려갈 곳이 없다 |
| 중첩 패턴, 식 형태 `match` | 검사기와 코드 생성이 커진다 |
| 표준 라이브러리 | 없다. 필요한 것은 프로그램이 자기 안에 쓴다 |
